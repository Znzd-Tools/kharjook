# E-FE-14 Settings

## Goal

The user can see the account, choose the display currency, open the notifications page, manage passkeys, and log out.

## In scope

- Account
- Passkeys
- Notifications page (Telegram, app push, per-notification switches)
- Logout

## Out of scope

- The Telegram chat itself
