# E-FE-14 Settings

## Goal

The user can see the account, link Telegram, manage passkeys, set notification switches, and log out.

## In scope

- Account
- Telegram link
- Passkeys
- Notification switches
- Logout

## Out of scope

- The Telegram chat itself
