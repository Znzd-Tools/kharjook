# E-FE-01 Shell and navigation

## Goal

A signed-in user can reach every screen, switch display currency, and see loading, empty, and error states in Persian RTL.

## In scope

- App chrome
- Primary and secondary navigation
- Currency toggle
- Sheets, toasts, confirms
- Not-found and install prompt

## Out of scope

- Visual style. That comes from the design prompt.
- Telegram chat UI
