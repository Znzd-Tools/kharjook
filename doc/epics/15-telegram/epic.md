# E-15 Telegram and notification settings

## Goal

The user can link a Telegram chat and use the bot for the same money actions the app exposes, with the same notification switches.

## In scope

- Link and unlink
- Webhook menus
- Quick add and undo
- Bank SMS draft
- Bot reports
- Notification settings

## Out of scope

- A second chat app
