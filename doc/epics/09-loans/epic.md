# E-09 Loans and installments

## Goal

The user can schedule installments, receive loan principal as income, and settle each installment in full or in part.

## In scope

- Loan create with schedule
- Asset-denominated loans
- Auto income
- Partial settle
- Edit and delete

## Out of scope

- Interest amortization tables
