## Look: Pastel dark

- **Dark first.** Purple-tinted dark canvas. The app opens in dark.
- **One soft accent.** Lilac with dark ink, for the main action, the active state and focus.
- **Pastel identity.** Categories, wallets and assets get one of six tints (rose, peach, lemon, mint, sky, lilac). Small tiles only — never whole rows.
- **One hero.** The pastel gradient card is for the single most important number on a screen.
- **Round and soft.** Pills for actions, 28px cards, circle avatars.
- **Solar icons.** `bold-duotone` for entities and navigation, `linear` for small glyphs. Import from `@/design-system/icons` only.

## Principles

1. **One primary action per screen.** Everything else is secondary, ghost or hidden in a sheet.
2. **Lists over cards.** Use `List` for collections. A `Card` only when content really needs a box.
3. **Numbers first.** Money is the content. Use `Amount` — big, tabular, Persian digits, a real minus sign.
4. **Fewer taps.** Smart defaults, quick chips (امروز / دیروز), one-tap `ChoiceGrid`, swipe and long-press actions.
5. **Color has a job.** Accent = main action, active state, focus. Green/red = money direction. Never decoration.
6. **Persian-first.** RTL, Jalali, تومان. Directional icons are mirrored (back = `ArrowRight`).
7. **Accessible by default.** 44px touch targets, visible focus rings, labels on icon buttons, color never the only cue.

## Usage

```tsx
// app/layout.tsx (once)
import { DesignSystemProvider } from '@/design-system';
<DesignSystemProvider>{children}</DesignSystemProvider>

// any component
import { Button, List, ListRow, Amount, toast } from '@/design-system';
```

Tokens live in `src/design-system/styles/tokens.css` and are imported by `src/app/globals.css`.
Use token classes only: `bg-panel`, `text-fg-muted`, `rounded-card`, `text-title`.

**Do not** use raw hex, `slate-*`, `purple-*` or `text-[11px]` in new code.

## Themes

Dark is the default. Set `data-theme="light"` or `data-theme="system"` on `<html>`.
All colors use CSS `light-dark()`, so one token works in both themes.
Use the theme switch in the Storybook toolbar to check every story in both.
